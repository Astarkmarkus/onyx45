# ONYX45 visual identity

Symbol: two offset cut-square forms with 45-degree internal cuts. Use the unaltered symbol with clear space at least one quarter of its width. Minimum recommended symbol size: 24 px (favicon exception).

Dark background: #11151B; panel #1A2029; text #F5F7FA; secondary #BFC7D0; lime #B1FF69; border #35404D. Use the lime for important actions and selected highlights.

The wordmark SVGs contain outlined vector lettering, with no external font dependency. PNG wordmarks and symbols have transparent backgrounds. “Dark” names refer to use on dark backgrounds; “light” names refer to use on light backgrounds.

Logo concepts were developed using the built-in image generation tool. The first concept was interpreted as deterministic SVG geometry and supplied in original vector and raster formats. No exclusivity or trademark registration is claimed.

## Concept generation

Qué utiliza esta web

Esta versión no instala cookies publicitarias ni analíticas. Utiliza el almacenamiento local del navegador para tu preferencia de privacidad (onyx45-privacy-v1) y, cuando lo permites, tu idioma (onyx45-language). No son identificadores publicitarios.

Tu elección

Usar preferencias necesarias permite recordar el idioma elegido. Continuar sin guardar el idioma elimina esa preferencia. La elección de privacidad se guarda igualmente para que el aviso no se repita en cada visita. Ambas opciones permiten navegar y preparar una consulta.

Duración y eliminación

Las preferencias permanecen en este navegador hasta que las cambies o borres los datos del sitio. El enlace de preferencias de privacidad del pie de página vuelve a abrir los controles. Al borrar el almacenamiento del navegador se elimina la elección guardada.

Formularios y servicios externos

Web3Forms tramita las consultas del formulario para su entrega y la prevención del spam. Solo recibe los datos cuando envías el formulario. Los servicios externos tienen sus propias políticas. Los proveedores de alojamiento pueden utilizar mecanismos de seguridad necesarios que quedan fuera del control de esta web estática.

Cambios futuros

Estas opciones no activan herramientas adicionales de publicidad o analítica. Antes de añadir seguimiento no esencial, deben actualizarse la implementación y esta política con los controles de consentimiento necesarios.

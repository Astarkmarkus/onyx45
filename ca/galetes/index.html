Què utilitza aquest web

Aquesta versió no instal·la galetes publicitàries ni analítiques. Utilitza l'emmagatzematge local del navegador per a la teva preferència de privacitat (onyx45-privacy-v1) i, quan ho permets, el teu idioma (onyx45-language). No són identificadors publicitaris.

La teva elecció

Utilitza les preferències necessàries permet recordar l'idioma triat. Continua sense desar l'idioma elimina aquesta preferència. L'elecció de privacitat es desa igualment perquè l'avís no es repeteixi en cada visita. Totes dues opcions permeten navegar i preparar una consulta.

Durada i eliminació

Les preferències es mantenen en aquest navegador fins que les canviïs o esborris les dades del lloc. L'enllaç de preferències de privacitat del peu de pàgina torna a obrir els controls. Si esborres l'emmagatzematge del navegador, s'elimina l'elecció desada.

Formularis i serveis externs

Web3Forms tramita les consultes del formulari per lliurar-les i prevenir el correu brossa. Només rep les dades quan envies el formulari. Els serveis externs tenen les seves pròpies polítiques. Els proveïdors d'allotjament poden utilitzar mecanismes de seguretat necessaris que queden fora del control d'aquest web estàtic.

Canvis futurs

Aquestes opcions no activen eines addicionals de publicitat o analítica. Abans d'afegir seguiment no essencial, cal actualitzar la implementació i aquesta política amb els controls de consentiment necessaris.

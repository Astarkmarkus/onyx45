Projecte intern d’ONYX45 002 · Generació de leads B2B / Projecte intern

D’una base de recerca a una prospecció estructurada.

El nostre desenvolupament comercial connecta recerca, qualificació, contacte i passos següents documentats.

002

El repte

Una llista d’empreses no crea oportunitats per si sola. La recerca, el contacte pertinent i el seguiment han de funcionar plegats.

El nostre enfocament

Identificar empreses, valorar-ne l’encaix, iniciar contacte, documentar el pas següent, concertar reunions quan sigui pertinent i revisar l’activitat.

  • Identificar i qualificar comptes
  • Contactar amb context
  • Documentar resultats i passos següents
  • Confirmar reunions i revisar l’activitat

Què vam construir

Un mètode de prospecció per al nostre propi desenvolupament comercial, a partir d’una base estimada d’unes 2.600 empreses facilitada pel fundador. Recerca, qualificació, contacte i passos següents tenen un lloc definit en el procés.

Projecte intern d’ONYX45 002

Una base estimada. Un procés per avançar.

Base de recerca declarada pel fundador
≈ 2 600*

* Aproximadament 2.600 empreses identificades, segons l’estimació del fundador per a la recerca comercial d’ONYX45. La xifra és aproximada i no s’ha verificat de manera independent.

Què demostra

La diferència entre una base de recerca, un intent de contacte, un seguiment i una reunió confirmada. Són activitats internes d’ONYX45, no resultats de campanyes de clients.

What counts as a booking?

A booking counts when a viewing appointment has been confirmed with the relevant landlord, agent or property contact for a property that reasonably matches the search criteria agreed with the customer.

  • A property link alone is not a booking.
  • An unanswered message is not a booking.
  • An unconfirmed viewing request is not a booking.
  • A confirmed viewing appointment counts as one booking.

A booking is delivered when the viewing appointment is confirmed. If the property contact cancels, we arrange a replacement booking.

A confirmed viewing does not mean you will receive or successfully rent the property. Packages cover the included number of bookings, not unlimited searching.
